# Локальный запуск Atlas за одну минуту

## Главная команда

Из корня проекта выполните:

```powershell
pnpm dev:start
```

После сообщения `Готово` сайт доступен по адресу `http://127.0.0.1:3000/`.

Чтобы команда сразу открыла сайт в браузере:

```powershell
pnpm dev:open
```

## Что это за проект

Atlas — демонстрационный сайт и каталог недвижимости Краснодара. Публичные страницы работают на Next.js 16, админка и схема данных принадлежат Payload CMS 3, данные хранятся в локальном PostgreSQL 18.

Локальная база проекта называется `atlas_realty_starter_dev`, её прикладная роль — `atlas_realty_starter_local`. Имена других клиентов в этом контуре запрещены.

Публичный путь данных: страница → SiteEngine → Public Gateway → Payload → безопасный DTO → интерфейс. Прямой анонимный доступ к бизнес-коллекциям Payload закрыт.

Подготовленный локальный набор:

- 60 опубликованных объектов: 30 квартир, 10 домов, 10 участков и 10 коммерческих объектов;
- 20 опубликованных жилых комплексов;
- связанные записи и локальные файлы медиа для всех 50 объектов;
- главная страница и каталог должны отвечать через `http://127.0.0.1:3000/`.

## Что делает команда

`pnpm dev:start` без Docker и без изменения данных:

1. читает именно проектный `.env.local`, не системные и не соседние настройки;
2. запрещает подключение к удалённой БД или базе без безопасного суффикса `_dev`, `_test`, `_staging`;
3. проверяет PostgreSQL 18 и совпадение всех миграций;
4. проверяет набор 60/20, наличие галерей и точное совпадение числа записей media с файлами в `media/`;
5. переиспользует исправный сайт на порту 3000 либо запускает новый;
6. подтверждает HTTP 200 для `/healthz` и `/`;
7. хранит локальные служебные секреты и PID только в игнорируемой папке `.local-dev/`.

Команда ничего не импортирует и не удаляет автоматически. Если данные или миграции разошлись, она останавливается с точной причиной.

## Ежедневные команды

```powershell
pnpm dev:start   # проверить всё и поднять сайт
pnpm dev:open    # то же самое плюс открыть браузер
pnpm dev:status  # показать ветку, безопасный адрес БД, данные и статус сайта
pnpm dev:stop    # остановить только процесс, созданный этим пультом
```

`pnpm dev:stop` не останавливает PostgreSQL и не трогает сайт, запущенный вручную или другим проектом.

## Правило для AI в начале работы

Сначала выполнить `pnpm dev:start` и открыть `http://127.0.0.1:3000/`. Если команда завершилась успешно, не исследовать повторно способ запуска и не перечитывать операционные документы без причины. Читать профильные документы только по реальному scope задачи.

При ошибке использовать текст команды как первичную диагностику. Полный ручной setup, восстановление миграций и правила безопасности находятся в `docs/OPERATIONS.md`.
