# ADR 0001 — Starter day-0 decisions

## Status

Accepted

## Decisions

- repository role: self-contained starter engine
- payload ownership: single schema/auth/admin/backend owner
- app routing: root layout + root not-found + payload route group
- public site: intentionally absent until external UI library is attached
- schema source: `src/payload/migrations-v2`
- ids: UUID in active V2 contour
- GraphQL: disabled
- localization: off
- deployment: isolated validation release on retained external server contour
- legacy client docs: archived, not active

## Consequences

- root `/` must return `404`
- public pages/components/assets can be deleted without preserving UI compatibility
- active docs must stay neutral
- repo rename and staging identity still require external follow-up
